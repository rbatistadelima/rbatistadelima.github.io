How to Use This Editor

  1. Upload an image using the file input, drag and drop, or paste from clipboard
  2. Customize your 3D text using the controls on the left
  3. Use the transform controls to move, rotate, or scale the text directly in the 3D view
  4. Adjust the camera by dragging with the mouse (orbit controls)
  5. When satisfied with your composition, export it as a PNG
