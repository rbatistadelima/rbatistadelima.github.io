MIDI Fixer for Guitar Pro 5

Repairs common MIDI import problems before opening in Guitar Pro 5: running status, SMPTE timing, channel 10 drums, bad note lengths, overlapping notes, strange controllers, and track names.

Download fixed MIDI
Note: this does not create a native .gp5 file. Guitar Pro 5 uses a proprietary format, so the goal is to export a cleaner MIDI that imports more reliably into Guitar Pro 5, then you save it as .gp5 inside Guitar Pro.
